# gordonpatterson.com

Gordon Patterson's UX design portfolio. A plain static site (no build step) —
homepage plus one page per case study, styled from `styles.css`.

## Pages
- `index.html` — homepage (portfolio grid, About, Contact)
- `microsoft-advertising.html`
- `bing-ads.html`
- `convrse.html`
- `myyard.html`

## Local preview
```
python3 -m http.server 8000
```
then open http://localhost:8000

## Deploy
Hosted on GitHub Pages from this repo.
